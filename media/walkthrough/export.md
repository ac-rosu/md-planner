# Share the plan

**Planner: Export…** writes to `plan/reports/<date>-<name>.<ext>`:

- **HTML status report**: one self-contained file with summary, milestones, Gantt, team load,
  risks, tests and punch items, in your company colours (`planner.export.branding`)
- **PDF** of the same report (uses Edge or Chrome)
- **Excel** workbook: tasks, schedule, team load, milestones, tests, punch list
- **MS Project XML** with calendars, dependencies and assignments
- **CSV**
- **Test report** with results, punch items and signatures

The bundled command-line tool runs the same exports, for example in CI (see the README).
